# Rollforward Format (Industry Standard)

The report uses a 3-column format with balance movements:

## Main Rollforward

| | Cost Basis | Unrealized G/L | Fair Value |
|---|------------|----------------|------------|
| Beginning Balance | $X | $X | $X |
| Purchases | $X | — | $X |
| Sales (at cost) | ($X) | — | ($X) |
| Reclassification to realized | — | ($X) | ($X) |
| Mark-to-market adjustment | — | $X | $X |
| **Ending Balance** | **$X** | **$X** | **$X** |

## Separate Realized Gains/Losses Schedule

| Security | Proceeds | Cost Basis | Realized G/L |
|----------|----------|------------|--------------|
| Security A | $X | $X | $X |
| **Total** | **$X** | **$X** | **$X** |
